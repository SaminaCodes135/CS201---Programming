🎓 Student Record Management System

A C++ Student Academic Management System for CS201 – Introduction to Programming

A console-based Student Record Management System developed as my first major project for CS201 – Introduction to Programming.

The project demonstrates the practical application of fundamental C++ programming concepts by providing a complete menu-driven system for managing student academic records.

📌 Project Overview

The Student Record Management System is a menu-driven console application designed to manage student academic information efficiently.

The system allows users to:

- Add new student records
- View existing records
- Update student information
- Delete records
- Search students by roll number or name
- Sort records using different criteria
- Calculate total and average marks
- Determine grades
- Determine pass/fail status
- Manage subjects according to academic groups

The project focuses on applying fundamental C++ programming concepts to a practical real-world problem.

▶️ How to Run

Requirements

Before running the project, make sure you have:

- A C++ compiler
- A C++ development environment such as Dev-C++, Code::Blocks, or Visual Studio
- A system capable of compiling standard C++ code

Steps

1. Download or Clone the Repository

Download the project from GitHub or clone the repository to your computer.

2. Open the Source File

Open:

StudentAcademicManagementSystem.cpp

in your preferred C++ IDE.

3. Compile the Program

Compile the source file using your C++ compiler.

4. Run the Program

Run the compiled application.

The program will display the main menu, allowing you to manage student academic records.

«Note: Student data is stored in memory while the program is running. Closing the program clears the current records because permanent file storage has not yet been implemented.»

🎯 Learning Objectives

This project was developed to strengthen my practical understanding of fundamental C++ programming and problem-solving concepts. Through building this system from scratch, I practiced:

- Problem Solving: Breaking a real-world problem into smaller, manageable programming tasks.
- Program Structure: Designing a complete menu-driven console application with a clear program flow.
- Functions: Creating reusable functions, function prototypes, parameters, return values, and modular program logic.
- Arrays: Working with one-dimensional and two-dimensional arrays to store and manage student data.
- Parallel Arrays: Managing related student information using multiple synchronized arrays.
- Character Arrays: Using C-style strings for names and subject information.
- Searching: Implementing search functionality using roll numbers and student names.
- Sorting: Implementing bubble sort to organize records by roll number, name, and total marks.
- Record Management: Practicing how to add, update, delete, shift, and display records.
- Input Validation: Handling invalid input, duplicate roll numbers, invalid marks, and other user-entry errors.
- Conditional Logic: Applying "if-else" and "switch" statements to control program behavior.
- Loops: Using "for", "while", and "do-while" loops for repetitive operations and menu handling.
- Academic Calculations: Calculating total marks, average marks, grades, and pass/fail results.
- Data Organization: Designing a structured approach for storing and displaying academic records.
- User Interaction: Creating clear menus, prompts, warnings, and messages for a better console experience.
- Debugging: Identifying, testing, and fixing logical and syntax errors during development.
- Code Organization: Separating different tasks into dedicated functions to make the program easier to understand and maintain.
- Real-World Application: Applying classroom C++ concepts to build a practical student record management system.
- Independent Development: Strengthening my ability to plan, implement, test, and improve a complete programming project.

This project represents my transition from basic C++ practice programs to developing a complete, structured, real-world console application.
